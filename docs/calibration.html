Calibration Scaffold

Load Bearing Simulator

A structure for scoring past episodes using only what was knowable at the time: draft the inputs with cited sources, lock them, and only then record what happened. Back to the simulator.

Scaffold only, no data. No episode is filled in, and no number here may be invented: every numeric input needs a cited source. Episodes stay in this browser; nothing is fetched or sent. Not financial advice.

Episode and rules

What I already knew about the outcome

Answer every item before locking. The answers and the statement below are part of each lock's hash. Each input below has a Help note; the same guidance is in calibration/GUIDE.md in the repository.

Sources

Inputs may cite only sources published on or before the as-of date. A source compiled later from period data counts for inputs only if its series is truncated on or before the as-of date. Outcomes must cite sources published after it.

Layer names (shared by every input version)

Input versions

Score the same episode with more than one set of inputs (for example a hype version and a measured version of adoption speed). Each version is locked separately. All versions share everything above; changing any of it after a version is locked needs a new episode version.

Settings

Each number needs a basis. Sourced and derived values need at least one cited source (comma-separated source ids), and derived values show their calculation. A judgement needs a rationale; its sources are optional, but an uncited judgement is labelled and keeps the episode file out of the repository.

Layer inputs

Outcomes

Entered only after every input version is locked. For each layer: did capital earn its cost? Yes and no need a source; contested needs at least one citation on each side; every outcome needs a note. Outcome sources must be published after the as-of date.

Model verdict against recorded outcome

Verdicts are recomputed with the current model, one column group per locked input version. Where a version was locked under a different model version, the cell says so.
